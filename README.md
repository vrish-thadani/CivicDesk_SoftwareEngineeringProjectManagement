# CivicDesk Case Study Presentation

This repository contains a professional presentation website for **Case Study 16: CivicDesk - Municipal Grievance Redressal for a City of 4 Million**.

## About the Project

The CivicDesk case study explores the challenges of municipal grievance redressal, where citizen complaints arrive through multiple unlinked channels (phone, web, counter, social media), leading to duplicate reports, unresolved issues, and a lack of accountability. 

This website serves as a digital presentation of the proposed CivicDesk solution, highlighting:
- **Executive Summary:** Core ideas and the political challenges of implementation.
- **Business Requirements & Scope:** Clear definitions of in-scope and out-of-scope objectives.
- **Stakeholder Strategy:** An influence vs. interest matrix.
- **System Design:** Architecture flow and deduplication pipeline.
- **Project Plan (PERT/CPM):** Critical path analysis and buffer justification.
- **Metrics Dashboard:** Anti-gaming strategies and SLA compliance.

## Technologies Used

- **HTML5:** Semantic structure for the presentation.
- **CSS3:** Custom professional styling (vanilla CSS, no frameworks). Features a modern corporate layout, custom properties, and responsive grids.
- **JavaScript (Vanilla):** Smooth scrolling and Intersection Observer API for scroll animations.

## How to View Locally

You can view the website by running a simple local HTTP server. 

If you have Python installed, run the following command in the project directory:

```bash
python3 -m http.server 8000
```

Then, open your web browser and navigate to: [http://localhost:8000](http://localhost:8000)
